# Horario INEM 11-08

Horario escolar estático para consultar las clases, cambiar entre días y abrir los enlaces de las clases virtuales.

## Probar

Abre `Calendario Escolar/Horario INEM 11-08.html` en un navegador, o usa la extensión Live Server de Visual Studio Code.

## Publicar

Publica la carpeta `Calendario Escolar` en cualquier servicio de alojamiento estático. No requiere servidor ni configuración adicional.

El horario está definido en la constante `classList` dentro del HTML. Para cambiar materias o enlaces, edita esos datos y vuelve a publicar el archivo.
